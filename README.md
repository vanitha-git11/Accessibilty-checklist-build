# Accessibility Checklist

## About
This project is an accessibility checklist designed to help create inclusive and user-friendly designs.

## Purpose
The purpose of this checklist is to review accessibility factors like visual clarity, navigation, content readability, and user experience.

## Checklist Categories
- Visual Accessibility
- Navigation Accessibility
- Content Accessibility
- Mobile Accessibility

## Tools Used
- Canva

## Features
✔ Easy-to-read design  
✔ Simple checklist format  
✔ Inclusive design guidelines

## Conclusion
Good design should be accessible for everyone.
